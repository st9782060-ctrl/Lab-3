**Мета роботи:** Формування у студентів теоретичної бази знань з алгоритмів з розгалуженням, умінь і навичок ефективного використання умовних операторів для програмування алгоритмів з розгалуженням.

---

## 1. Відповіді на ключові питання

1. **Що таке умовний оператор?**  
   **Умовний оператор** — це конструкція мови програмування, яка дозволяє змінювати порядок виконання інструкцій залежно від істинності або хибності заданої логічної умови.

2. **Які є умовні оператори?**  
   У мові програмування C++ існують такі умовні оператори:
   * `if` — скорочена форма розгалуження;
   * `if ... else` (та каскад `if ... else if ... else`) — повна форма розгалуження;
   * `switch` — оператор множинного вибору;
   * `? :` — тернарний умовний оператор.

3. **Яка структура `switch`?**  
   Оператор `switch` обчислює цілочисельний або символьний вираз і порівнює його значення з константами у гілках `case`:
   ```cpp
   switch (вираз) {
       case константа_1:
           // інструкції
           break;
       case константа_2:
           // інструкції
           break;
       default:
           // інструкції за замовчуванням
           break;
   }
